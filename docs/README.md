# Design notes

One page per system, stating the rules the way they were decided. When a rule changes, change the page first, then the code.

- keys.md: keys, slots, wheels, menus
- pip.md: how Pip talks, leads and reminds
- crafting.md: the mat, the lesson, the wooden sword, materials
- farming.md: patches, seeds, pulling crops, gathering
- tutorial: the early game order lives in code as data, src/tutorial.js (TUTORIAL), and reads like a list

HANDOFF.md is the build-by-build engineering log; PROJECT_INSTRUCTIONS.md the working agreement for delivery.
