Quest: a browser RPG (Zelda meets EarthBound) in a single index.html, hosted at https://worthcreation.github.io/quest/ from the repo worthcreation/quest (personal GitHub account). The repo holds everything: index.html, src/ (source by topic, load order in src/ORDER), tests/, tools/, docs/ (design notes, HISTORY.md, PROJECT_DESCRIPTION.md), HANDOFF.md, QUEST_WAYS_OF_WORKING.md, PROJECT_INSTRUCTIONS.md.

Start of every chat: git clone https://github.com/worthcreation/quest.git into /home/claude, read HANDOFF.md and QUEST_WAYS_OF_WORKING.md in full, then edit the files in src/. Build with: sh build.sh (it also checks the built script parses). Test with: node tests/run.js (every test in tests/, about 2 minutes, one call; each prints errs N, 0 is a pass) and node tools/overlap.js (want 0). The build number is const BUILD in src/draw.js; bump it every build.

Delivery: one download per build, quest-bNN.zip, laid out like the repo root (index.html, src/, tests/, tools/, docs/, HANDOFF.md, QUEST_WAYS_OF_WORKING.md, PROJECT_INSTRUCTIONS.md; no node_modules). Every build updates HANDOFF.md (current state) and adds a short entry at the top of docs/HISTORY.md. At a handoff (end of a chat, or when asked), also refine these project instructions (PROJECT_INSTRUCTIONS.md) to match the source, and the project description (docs/PROJECT_DESCRIPTION.md) only if the game's mood, theme or direction has changed; give both as copyable text for the claude.ai Project, always the full current file (a note of what changed is welcome, but never instead of the whole thing). End each reply with the ship command for Windows PowerShell (5.1 has no &&, so steps are joined with ;), in a ```powershell code block so it shows in colour:
cd ~\quest -ErrorAction Stop; Expand-Archive -Force ~\Downloads\quest-bNN.zip .; Remove-Item ~\Downloads\quest-bNN.zip; git add -A; git commit -m "Build NN: ..."; git push
(-ErrorAction Stop makes the whole line stop if the folder isn't there, so nothing unzips or deletes in the wrong place; the repo lives at ~\quest, cloned once with: git clone https://github.com/worthcreation/quest.git $HOME\quest) and a play link with a fresh 7-digit prime seed: ?seed=N. Also when relevant: ?arena, ?puzzle, ?mountain (the climb screens; keys 1 to 5), ?scene=<id> (start on any screen).

Ways of working: build features headlessly and test them with the node harness (tests/<topic>.js through tests/harness.js: eval index.html with a fake canvas, seeded randomness, fixed world seed) before delivering; tests play it like a person (walk, press, wait). Report what was tested, plainly, with numbers. Render PNGs with tools/shot.js when visuals change and look at them. For looks that aren't settled, show still mockups first, no build. Keep arena, puzzle and test modes on the same code as the main game. Lay out anything jumpable in tiles at enterScene, not in screen fractions. Collision and drawing share one shape function; never draw an edge the game doesn't test. Delete what lost its purpose in the same build. No em dashes in replies; concise, candid, no AI-sounding filler.

Design rules to keep: gusts come in sets of three (two gentle, one strong), only the strong one carries you, landing on a ledge; your shadow shows where you'll land (small at the top of a jump, leading toward the landing). Rocks are buried and must be knocked loose (stomp), then rocked and heaved; single cracking boulders take thrown rocks; no pressure plates, logs or ropes. Rough stones are faceted with a zigzag soil line where they meet the ground; throwing stones are lumpy, each its own shape. Say "rich soil", never "tilled"; the shelter is a lean-to, never a tent. One alert style: small scrolls near the bottom (pickups too); full banners only when a quest starts or ends. The HUD sits bottom-right (vigor bar and the A S D F slots) and fades when quiet; the quest note is top-right. R opens the slot wheel; while R is held, A S D F choose which key to set. F at a patch opens the plant/compost menu. The pack is an icon belt; the Map tab is a page for every place you've been, purple where a found mushroom is; nothing about spores until they answer you. Anything you gain shows in the pack. Pip and NPC lines hold until F; tutorial lines are free; Pip teaches in his own bubble and a slot flashes when Pip suggests using it. Pip is "Pip", never "they"; Pip leads on one side of your path at about half your speed. Items rest on the ground and are picked up with F. Skills level quietly: one flavour line per level, details on the Status page. Quests: current objectives on top, folded log below, newest first.

Story so far: you choose a name and colour; the game opens on the old jetty mid-conversation; Pip waits by the garden; the robin hides until you pound by its tree, then drops seeds; plant two (quest: Pip's garden); Pip leads to the camp spot (quest: Set up camp; lean-to already up); gather river stones (the last ones are inside a boulder you break with a stuck stone Pip shows you how to loosen), sticks (a few lying about, the rest shaken from trees with a pound) and rabbit fluff; glue, fire ring and workbench on the mat (3 slots); twilight and the lantern in the lean-to; the woods at dusk: a gremlin peeks, another taunts, then an ambush takes Pip; break the boulders; the sword in a stump by a bramble cluster; the cave; the rescue; spores carry you home; morning, and the journal quest. Beyond: the windy fields and mountain path, the crags and the High Reaches above the old summit, spore travel between found mushrooms, Wick's cellar. The climb screens (climb1 to climb5) are in testing and not yet joined to the world.
