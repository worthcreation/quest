Quest: a browser RPG (Zelda meets EarthBound) in a single index.html, hosted at https://worthcreation.github.io/quest/ from the repo worthcreation/quest (personal GitHub account). The repo holds everything: index.html, src/ (split parts), tests/, tools/, HANDOFF.md.

Start of every chat: git clone https://github.com/worthcreation/quest.git into /home/claude, read HANDOFF.md, and edit the parts in src/. Assemble with: cd src && cat head.html p1.js p2.js p3.js p4.js p6.js p7.js p8.js p9.js p10.js p11.js p12.js p13.js p14.js p5.js > ../index.html (p5 last). Current build number is in p7.js (const BUILD); bump it every build.

Delivery: one download per build, quest-bNN.zip, laid out like the repo root (index.html, src/, tests/, tools/, HANDOFF.md, PROJECT_INSTRUCTIONS.md; no node_modules). Update HANDOFF.md in it every build. End each reply with the ship command:
cd ~/quest && unzip -o ~/Downloads/quest-bNN.zip && rm ~/Downloads/quest-bNN.zip && git add . && git commit -m "Build NN: ..." && git push
and a play link with a fresh 7-digit prime seed: ?seed=N (also ?arena&seed=N and ?puzzle&seed=N when relevant).

Ways of working: build features headlessly and test them with the node harness (tests/t*.js style: eval index.html with a fake canvas) before delivering; report what was tested, plainly, with numbers; render PNGs with tools/shot.js when visuals change. Keep arena and puzzle modes on the same code as the main game (they only add a hub, a kit and System items). Lay out anything jumpable in tiles at enterScene, not in screen fractions. No em dashes in replies; concise, candid, no AI-sounding filler.

Design rules to keep: gusts come in sets of three (two gentle, one strong), only the strong one carries you, and it lands on a ledge with a landing shadow from the apex; wind never pushes you in the air or on rock/ledges. Rocks are buried and must be knocked loose (stomp), then rocked and heaved; cracked stones and the gremlin burrow need a thrown rock; no pressure plates. Say "rich soil", never "tilled". Text boxes are placed once and stay fixed; prompts are a half-strength ring + key label, tips live in the menu marquee. Slots A S D F sit under the vigor bar: whatever is in a slot, that key uses it; empty slots draw nothing; new things auto-fill empty slots (weapons into F) and never overwrite. F is also the dynamic action. Hold R for the wheel (use now), R + slot key to set a slot. D backs out of menus, F selects. Wearables (armaments, charms, flair) are chosen in the pack's Wear tab and always visible on the hero. Reuse the one slot model (slotOptions/useEntry/setSlot) rather than new per-feature lists. Speech and quest alerts hold until F (or a tap); Pip walks to what Pip points out and waits there; Pip is named "Pip", never "they". Items rest on the ground with an occasional glimmer. Skills level quietly: no numbers, one flavour line per level in #c9a2ff. Quests tab: current objectives on top, folded log below, newest first.

Story so far: opens on the old jetty mid-conversation (free to wander, exits closed until Pip's three lines are read and Pip heads south), Pip waits by the garden, robin seed lesson (first drop guaranteed), plant two seeds (quest: Pip's garden), Pip leads to the camp spot (quest: Set up camp; lean-to already up), gather river stones / forest sticks / rabbit fluff with Pip saying what's still needed, craft glue then fire ring and workbench on the mat (2 slots, then 3), twilight scene by lantern light in the lean-to, forest map run at dusk, gremlins take Pip down a small weird hole, smash it open with a rock, sword at w3.
